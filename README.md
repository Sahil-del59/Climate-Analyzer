# Climate Data Analyzer

A lightweight command-line tool built in Python and NumPy to analyze historical climate data, compute statistical summaries, and export automated reports.

## Features
* **Data Ingestion:** Reads multi-column CSV temperature datasets using NumPy.
* **Statistical Analysis:** Computes average, maximum, and minimum temperature statistics using vectorized operations.
* **Automated Reporting:** Exports generated insights into a clean `climate_report.txt` file.

## How to Run
1. Ensure you have Python and NumPy installed.
2. Run the analysis script in your terminal:
   ```bash
   python miniproject3.py
